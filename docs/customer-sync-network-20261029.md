# 2026-10-29 客户用量、账单与国内官网入口修复

## 根因和修复

- Redis 原 maxmemory 48 MiB，实测 48.05 MiB，noeviction 下持续拒绝写入。上游日志明确 OOM，登录接口因此返回 429；用量与研究定时任务失败，客户页面保留了 10/24 的旧快照。
- 只读分类统计发现约 69,090 个 token_family、69,094 个 refresh_token。后台原先每分钟为各账户重新登录并产生长寿命会话。
- 热恢复 Redis 到 96 MiB，容器限制 160 MiB，保留 noeviction 和 AOF；没有清空 Redis 或数据库。Compose 已持久化并重建 Redis 验证，不依赖易丢失的临时 CONFIG SET。
- 新增按账户凭据摘要隔离的跨进程 access-token 缓存，最多复用 15 分钟且早于上游到期。文件锁避免并发重复登录，目录 0700、文件 0600，不保存密码或 refresh token；拒绝的 token 会失效，下次请求重新登录，计费写入不自动重放。
- 主账户采集失败仍继续各客户独立采集，旧共享额度标记过期。累计统计显式查询全历史，避免上游默认日期区间把旧账户累计显示成零。
- 只读健康检查增加 Redis 80% 内存门槛；这不是独立后台告警或无限巡检。

## 官网入口

- 修复前，同一轮广州电信 AS4134 返回200，深圳阿里云 AS37963 连 Render IP 216.24.57.1 的 TCP 超时20秒。该深圳节点连现有 API 服务器成功。
- 官网 A 记录改为现有 159.203.4.206；www CNAME 跟随主域名，TTL600。Caddy 经校验 HTTPS 转发至已存在的 tokenbots-quota.onrender.com，www 重定向主域名；不缓存登录、账户或账单响应。原 API 域名与路由保持。
- 上线前本机预检 /console 与 /api/pricing 均成功，主域名有效 TLS 已验收。
- 用户明确保持 Render 免费规格。没有购买套餐、升级实例或迁移网站数据库；冷启动等待仍存在，新入口不能消除免费源站休眠。
- 原 DNS TTL 为1小时，部分递归 DNS 会暂时沿用旧IP。本轮广东探针均记录实际解析IP，不能将指定IP测试冒充客户端DNS已更新。
